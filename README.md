# 하폐수처리장 360° 위험성평가 사용법

## 실행하기

1. `index.html`과 `site.jpg`가 같은 폴더에 있는지 확인합니다.
2. `index.html`을 더블클릭하면 크롬 또는 엣지에서 바로 열립니다.
3. 설치나 서버 연결은 필요하지 않으며, 입력 내용은 이 브라우저 안에만 자동 저장됩니다.

## 현장 사진 둘러보기

- 사진을 마우스로 끌거나 화면 가장자리에 마우스를 대면 좌우로 이동합니다.
- 오른쪽 위 `−`, `＋`로 축소·확대하고 `처음 시점`으로 돌아갈 수 있습니다.
- `360° 이어 보기`는 사진 양끝을 이어서 보여주며, 버튼을 눌러 `끝에서 멈춤`으로 바꿀 수 있습니다.
- 왼쪽 아래 미니맵을 누르면 해당 위치로 이동합니다.
- `사진 바꾸기`는 컴퓨터의 다른 사진을 임시로 엽니다. 원본 사진은 수정되지 않습니다.

## 핀 추가·수정하기

1. `＋ 핀 추가`를 누른 뒤 사진에서 위험 위치를 클릭합니다.
2. 오른쪽 `선택한 핀`에서 유형, 위험요인, 점수 근거, 개선대책 등을 입력합니다.
3. 핀 위치는 다음 네 가지 방법으로 고칠 수 있습니다.
   - 사진 위의 핀을 마우스로 끌기
   - 미니맵의 점을 마우스로 끌기
   - `핀 위치(사진 기준 %)`의 x, y 숫자 입력
   - `📍 위치 다시 찍기`를 누른 뒤 사진의 정확한 위치 클릭
4. 핀을 선택한 상태에서 방향키로 조금씩 옮길 수 있습니다. `Shift + 방향키`는 더 크게 옮깁니다.
5. 위험도는 `빈도(1~5) × 강도(1~4)`로 자동 계산됩니다.

## AI 분석 결과 불러오기

1. `AI 결과(JSON) 붙여넣기`를 누릅니다.
2. AI가 만든 JSON 전체를 붙여넣습니다. 앞뒤 설명이나 ``` 표시가 있어도 배열 부분을 찾아 읽습니다.
3. 현재 핀을 유지하려면 `추가`, 모두 바꾸려면 `기존 핀 지우고 바꾸기`를 누릅니다.
4. 좌표가 0~1이면 자동으로 0~100%로 변환됩니다. 불러온 뒤 실제 사진을 보고 핀 위치를 반드시 확인하세요.

예시 형식:

```json
[{"x":25,"y":40,"유형":"추락","위험요인":"점검 중 작업자가 열린 개구부 때문에 아래로 추락할 수 있음","법적기준":"확인 필요","빈도":2,"강도":4,"빈도근거":"현장 출입 빈도 확인 필요","강도근거":"추락 시 중상 가능","개선대책":"[공학] 고정식 덮개와 안전난간 설치","관리방법":"작업 전 덮개 상태 확인"}]
```

## 저장·인쇄하기

- `작업 저장`: 전체 핀과 입력 내용을 JSON 파일로 저장합니다.
- `작업 불러오기`: 이전에 저장한 작업 JSON 파일을 다시 엽니다.
- `위험성평가표 CSV`: 엑셀에서 한글이 깨지지 않는 CSV 파일로 저장합니다.
- `인쇄(게시용)`: 핀 번호가 표시된 전체 사진과 위험도순 평가표를 A4 가로로 인쇄합니다.
- `핀 모두 제거`: 모든 핀을 삭제합니다. 되돌릴 수 없으므로 먼저 `작업 저장`을 권장합니다.

## 주의사항

- 사진 분석에서 보이지 않는 사항은 현장에서 직접 확인해야 합니다.
- 법적 기준의 조문은 원문을 확인한 뒤 사용하세요.
- 최종 위험 판단과 결재는 안전관리자가 직접 수행합니다.
- 사진과 입력 내용은 외부로 전송되지 않습니다.
